Политика конфиденциальности

Дата редакции: 17 октября 2026 года.

Local YouTube Shorts — личное локальное приложение владельца GitHub-профиля dzekovdzek. Оно предназначено для отправки выбранных владельцем видео на его YouTube-канал.

Какие данные обрабатываются

  • Выбранные MP4 и заданные пользователем метаданные: заголовок, описание, теги, категория, язык, аудитория и приватность.
  • Название и идентификатор своего канала, полученные через YouTube API.
  • OAuth-реквизиты, необходимые для разрешённых API-запросов.
  • Локальная история загрузок: путь и SHA-256 файла, дата, метаданные, Video ID, ссылка, канал, приватность и статус обработки.

Для чего нужны разрешения Google

youtube.upload позволяет отправить выбранный видеофайл и его метаданные. youtube.readonly позволяет проверить канал и результат отправки. Приложение не получает пароль Google. Вход и согласие выполняются владельцем на странице Google.

Хранение и передача

Видео и метаданные передаются с компьютера владельца напрямую в Google/YouTube по HTTPS. OAuth-токен и адреса незавершённых сессий загрузки хранятся локально с шифрованием Windows DPAPI для текущего Windows-пользователя. Реквизиты Desktop client и журнал загрузок также хранятся на компьютере владельца. В приложении нет собственного внешнего сервера хранения, рекламы или встроенной аналитики.

Если владелец использует Codex для запуска программы, отдельные результаты команд, например название канала, Video ID и статусы, могут обрабатываться этим сервисом в соответствии с настройками владельца. Сам загрузчик не отправляет видео или OAuth-токены модели ИИ. Секреты нельзя включать в сообщения и диагностические логи.

Использование Google user data

Загрузчик использует данные только для описанных функций личной загрузки и проверки видео. Он не продаёт данные и не использует их для рекламы или обучения моделей. Использование информации, полученной через Google APIs, соответствует Google API Services User Data Policy, включая требования Limited Use.

Срок хранения, отзыв доступа и удаление

Локальные данные сохраняются до их удаления владельцем. Доступ приложения можно отозвать в настройках подключений Google-аккаунта. После остановки программы владелец может удалить локальные токены и реквизиты клиента. Журнал можно удалить отдельно, учитывая, что это снимет защиту от повторной отправки файлов. Удаление локальных данных не удаляет видео с YouTube; ими владелец управляет через YouTube Studio.

Этот информационный сайт

На сайте нет форм, авторизации, загрузки файлов, рекламы или сторонних аналитических скриптов. При размещении на GitHub Pages хостинг GitHub может обрабатывать технические данные посетителей, включая IP-адреса, для безопасности. Подробности — в политике конфиденциальности GitHub.

Связь

Связаться с владельцем можно через страницу проекта GitHub. Обращения там публичны: не прикладывайте токены, пароли, конфиденциальные видео и другие секретные данные.
