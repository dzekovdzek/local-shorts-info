Local YouTube Shorts — локальная программа для отправки готовых MP4 на YouTube-канал владельца через YouTube Data API v3.

Эта страница описывает личное приложение. На сайте нет входа в Google, приёма видео или доступа к каналу.

Как работает приложение

Владелец выбирает готовый MP4 и задаёт заголовок, описание и параметры аудитории. Программа проверяет файл и Channel ID, отправляет видео напрямую в YouTube и сохраняет локальную историю загрузки. Поддерживаются продолжение после обрыва связи и проверка уже отправленных файлов.

По умолчанию доступ к видео — private. Открытая публикация требует отдельного разрешения владельца. Программа предназначена для личного использования и не предоставляется как сервис для других пользователей.

Загрузка видео

youtube.upload используется для отправки выбранного видео и его метаданных. На странице Google это разрешение может называться «Управление видео на YouTube».

Проверка результата

youtube.readonly используется для получения своего канала, сверки его ID и проверки приватности и статуса обработки отправленного видео.

Где находятся данные

Программа работает на компьютере владельца. Google-пароль вводится только в браузере Google. OAuth-токены хранятся локально с шифрованием Windows DPAPI. Этот информационный сайт не получает OAuth-токены, метаданные загрузок или видеофайлы.

Подробности хранения, передачи и удаления данных описаны в политике конфиденциальности. Использование приложения регулируют условия использования.
